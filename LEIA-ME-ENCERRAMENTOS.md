# Encerramentos padronizados — Dois Pontos de Vista

Atualização dirigida às páginas de Estante, Leituras a Dois, Sobre Nós, Livro e Opinião.

O componente `src/components/Encerramento.astro` centraliza as regras visuais.
- Principal: vinho.
- Secundária: contorno vinho.
- Terciária: link discreto.
- No celular, botões empilhados e com largura confortável.
- O conteúdo e o destino permanecem específicos de cada página.
- A seção de destaque do outro autor nos perfis permanece separada por ser uma apresentação com foto.

Para instalar, copie `src/` sobre a pasta `src/` existente. Não substitua seu `index.astro`: o pacote desta atualização não o modifica, preservando as correções mais recentes do carrossel.

Após instalar, rode `npm run build` e `npm run dev`.
