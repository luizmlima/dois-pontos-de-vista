# Dois Pontos de Vista — revisão visual consolidada

## Instalação
1. Salve uma cópia do projeto atual.
2. Extraia o ZIP e copie o conteúdo da pasta `dois-pontos-de-vista-final-visual` para a pasta do projeto. Confirme substituições.
3. Preserve a sua pasta `node_modules` já instalada.
4. Execute `npm run build` e depois `npm run dev`.

## Padronização
- Uma imagem oficial de logo compartilhada pelo cabeçalho, rodapé, Home e destaque de Leituras a Dois.
- Nova identidade para o favicon.
- Home centralizada no celular, sem ilustração grande no mobile.
- Leitura dos artigos continua alinhada à esquerda.
- Carrossel: 3 cartões desktop, 2 tablet, 1 celular, com setas e deslize por toque.
- Mesma paleta e detalhes de interação em todas as páginas.

## Ainda pendente
Conteúdos de livros e notas ainda são demonstrativos. Markdown e CMS ficam para a próxima etapa.
